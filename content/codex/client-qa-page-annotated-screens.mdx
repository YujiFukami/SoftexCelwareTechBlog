お客様のご質問に、画面のスクリーンショットに赤枠と吹き出しを付けて答える資料を、毎回手で作るのは時間がかかります。画像を送るだけでは、どの質問への答えなのか、お客様がどこに返事を書けばよいのかも分かりにくくなります。

そこで、注釈付きの画面画像を自動で作り、質問ごとにコメントできるWebページにまとめる形にしました。

## ページの組み立て

1. ページの上に、お客様からのご連絡を載せ、質問の行を赤枠と「Q1」などの札で囲む。札はそのお答えへのリンクにする
2. Qごとに、次の順で並べる
   - お客様のメッセージのスクリーンショットに、該当の行の赤枠とQ番号を描き込んだ画像（他の行は薄くする）
   - 「A」と一言の答え
   - 注釈付きの画面画像（赤枠、番号、吹き出し）と説明
   - 「ご確認したいこと」の枠
   - 「このお答えにコメントする」ボタン
3. 最後に「打ち合わせで決めたいこと」をまとめる
4. 画像は押すとページ内で拡大し、もう一度押すと実際の大きさで表示する

ページは<Term>Claude</Term>のArtifact（Claudeが作って共有できるWebページ）として公開しました。コメント欄の機能を有効にして、各Qのボタンから、その見出しに対するコメントの入力欄を開くようにしています。コメントの一覧はClaudeの画面側に表示されます。

## 注釈付きの画面画像を自動で作る

プレビュー用のHTMLの`</body>`の前に、注釈を描くスクリプトを差し込んでから、ヘッドレスのChromeで撮影します。スクリプトは、注釈の定義（JSON）を読み、画面が描かれた後に要素の位置を測って、赤枠、番号、吹き出しを描きます。

~~~json
[
  { "sel": "#btn-save", "text": "ここで<b>保存</b>します", "dx": 40, "dy": 10, "w": 220 },
  { "sel": ".row", "nth": 2, "text": "2行目に入ります", "left": true, "pad": 4 }
]
~~~

項目は、CSSセレクタ、吹き出しの文、吹き出しの位置（右へ、下へ）、幅、左に出すか、何番目の要素か、枠の余白です。

- 撮影は`--screenshot=C:/…png --window-size=幅,高さ --virtual-time-budget=7000`で行う。スマホの画面は幅500で撮る（それより狭いと切れた）
- セレクタが見つからないときは、`document.title`に印を付ける。`--dump-dom`で確かめられる
- **必ず画像を目で見る**。吹き出しの重なりやはみ出し、ボタンを隠していないかを確認し、位置を直して撮り直す

## メッセージのスクリーンショットに赤枠を描く

文字の暗い画素がある行のまとまりから、メッセージの各行の位置を測り、質問の行に赤枠とQ番号を描き込みます。<Term>Python</Term>と<Term>Pillow</Term>で処理します。

## 注意点

- コメントを書いてもらうには、お客様を「コメントできる」権限で招待する必要がある
- お客様のメッセージのスクリーンショットにはお名前が写るので、ページは**お客様ご本人にだけ**共有する
- ページ内リンクと画像の遅延読み込み（`loading="lazy"`）を組み合わせると、ヘッドレスのChromeで真っ白に写ることがあった。手元の確認では遅延読み込みを外し、縦長に撮って切り出す
