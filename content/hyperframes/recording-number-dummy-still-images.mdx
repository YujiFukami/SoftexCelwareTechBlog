業務アプリの操作録画を紹介動画に使うとき、入力欄や結果の画面に会員番号などの番号が映ることがあります。隠したいものが、入力前、入力中、結果の状態ごとに違う場所へ出る場合もあります。

動画のままモザイクをかけると、時間で切り替わる範囲の管理と確認に手間がかかります。そこで、状態ごとの静止画を加工して、<Term>HyperFrames</Term>で切り替える方法を使いました。

## 静止画に置き換える考え方

1. 「入力前」「入力中」「結果」など、状態ごとに録画から静止画を1枚ずつ切り出す
2. <Term>FFmpeg</Term>で、番号の部分を背景色で塗りつぶし、ダミーの番号を描き込む
3. HyperFramesで静止画を順に切り替え、動いているように見せる

静止画なので、確認は書き出した数枚を見るだけで済みます。ダミーの番号は画素に焼き込まれるので、元の番号は制作物のどこにも残りません。

## 塗りつぶしとダミー番号の描き込み

塗る色は、元の画面の画素から取ります。

~~~bash
# 指定した1画素の色を16進で表示する
pick(){ ffmpeg -v error -i "$1" -vf "crop=1:1:$2:$3,format=rgb24" -f rawvideo - | od -An -tx1; }
~~~

~~~bash
cd tools   # フォントを作業フォルダへコピーしておく
FONT=arial.ttf

ffmpeg -ss 822 -i "$SRC" -frames:v 1 -vf "crop=420:560:750:360,\
drawbox=x=60:y=85:w=300:h=49:color=0x2B3144:t=fill,\
drawtext=text='123456':fontfile=$FONT:fontcolor=0xE8EDF8:fontsize=22:x=68:y=97,\
crop=378:386:20:22,scale=1134:-1:flags=lanczos" result.png
~~~

Windowsでは、`drawtext`の`fontfile`に`C:/...`の形で書くと、`:`の解釈に失敗します。フォントを作業フォルダへコピーし、相対パスで渡すと確実です。

## 入力の動きを再現する

入力中の画面を1桁ずつ用意し、時間に合わせて表示を切り替えます。

~~~js
// [要素のid, 表示を始める秒]
const seq = [["#s0", 0], ["#s1", 1.6], ["#s2", 1.8], ["#sb", 3.1], ["#sr", 4.2]];
seq.forEach(([id, t], i) => {
  tl.set(id, { opacity: 1 }, t);
  if (i) tl.set(seq[i - 1][0], { opacity: 0 }, t);
});
~~~

## きれいに仕上げるポイント

- 塗る範囲は入力欄の内側だけにする。角まで塗ると、角の丸い枠線が欠ける
- クリック位置を示す強調表示も、ボタンの色で塗って消す
- マウスカーソルが重なったコマは避ける。1秒おきのコマを一覧画像にして、使うコマを選ぶ
