Excelの報告書に点検写真を貼り付けるツールの操作録画を、紹介動画に使ったときの方法です。この種の録画では、隠すべき情報が画面のいろいろな場所に散らばっています。

- タイトルバー：発注者の様式名
- 名前ボックス：画像の名前（実際の番号入り）
- ステータスバー：処理の完了メッセージと、案件フォルダを含むフルパス
- シートのタブ：場所を表す名前
- 左の列：実際の管理番号
- 設定シートのセル：フォルダのフルパス
- 処理の最後にエクスプローラーが開く瞬間

## モザイクより先に、切り落としで片付ける

報告書の画面は、**見出しの行から下、写真の列だけ**を<Term>FFmpeg</Term>の`crop`で切り出します（例：`crop=1090:618:468:338`）。これだけで、番号の列、表題、タブ、ステータスバーがまとめて画面の外に出ます。

- 確認用のシートなど、番号の列が左端にある画面も、その列を外して切り出す
- 番号の列を外せない画面（番号と写真番号が並ぶ表など）だけ、その列とファイル名の番号部分にモザイクをかける。`scale=iw/18`程度に縮小してから戻すと読めなくなる

## 別のウィンドウが開く瞬間の手前で切る

ボタンを押した直後に別のウィンドウが開く場合は、0.1秒ごとのコマを一覧画像にして、開く瞬間を探します。

~~~bash
ffmpeg -ss 335 -t 4 -i input.mp4 -vf "fps=10,scale=320:-1,tile=6x4" -frames:v 1 sheet.png
~~~

この事例では、5分37.1秒にエクスプローラーが開いたので、5分37.0秒で切りました。報告書が開く瞬間も同じように探し、その前に映る設定シート（パス入り）を含めないようにしました。

## BGMより長い本編は、2本目を重ねてつなぐ

改善効果の説明を加えると本編が55〜60秒になり、32.7秒のBGMが途中で切れて無音になりました。そこで、本編がBGMより長いときだけ、2本目を少し重ねてフェードでつなぎます。

~~~js
const BGM = 32.7;
// 1本目のフェードアウトは短く（0.6秒）しておく
if (total - afterIntro > BGM) {
  const s2 = f(afterIntro + BGM - 0.6);
  audio.push(`<audio id="bgm-main2" class="clip" src="assets/audio/bgm.wav"
    data-start="${s2}" data-duration="${f(total - s2)}" data-media-start="0"
    data-track-index="12" data-volume="0.12" data-fade-in="0.6" data-fade-out="1.2"></audio>`);
}
~~~

2本目は、1本目とは**別のトラック番号**にします。同じトラックで重ねないためです。縦長版でも、本編がBGMをわずかに超えると同じ処理が入ります。

## 確認のポイント

- 自動で作ったコマの一覧やOCRは、ステータスバーや名前ボックスの小さな文字を拾いません。報告書の画面は、必ず元の解像度で1枚確認します
- 写真がダミーの録画でも、ファイル名や表の番号は本物のことがあります。「写真がダミーなら全部ダミー」とは考えません
