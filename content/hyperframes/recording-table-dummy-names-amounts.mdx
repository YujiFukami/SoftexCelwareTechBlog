お客様の表計算の録画を紹介動画に使うとき、担当者の名字や科目名、売上の金額が、表いっぱいにほぼ全編で映ることがあります。

モザイクやぼかしにすると、表の大半がぼけて「何の画面か」が伝わりません。サムネイルに使うと特に見づらくなります。手でダミーを描き込むには行が多すぎ、スクロールする場面は静止画にもできません。

そこで、動画のコマごとに文字を見つけて、ダミーの文字に描き替えました。

## 名前の列：文字の「形」で見分ける

列のx座標の範囲だけを決めておき、その中の文字のかたまり（行）を自動で見つけて、セルの背景色で塗り、「担当A」「科目01」などを描き込みます。同じ名前は同じ形の文字なので、形を比べて同じダミーを当てます。

- **行の見つけ方**：列の中で暗い画素（灰色の度合いが140未満）がある行をまとめる。20pxより高いかたまりは、行がくっついたとみなして16pxずつに分ける
- **形の比べ方**：濃い画素だけで2値にし、1画素のずれを許して「違う画素の数÷どちらかが黒の画素の数」を測る。名前は0.4以下、科目は0.12以下で同じとみなす
- **背景色**：かたまりの周りの明るい画素で、一番多い色
- **マウスカーソル**：幅14px未満、高さ18px以上のかたまりは文字ではないので、塗るだけにする

動画は10コマ/秒で書き出して処理し、30fpsでつなぎます（3倍速になります）。形とダミーの対応は、動画を通して持ち越します。

~~~bash
ffmpeg -framerate 30 -i frames/%05d.png -vf "crop=1050:620:50:300" \
  -c:v libx264 -pix_fmt yuv420p -crf 18 out.mp4
~~~

対応はおおむね合っていれば十分です。違う科目が同じダミーになることもありますが、画面の下に「担当者名・科目名はダミーの表示」と書いておけば、見る人に伝わります。

## 金額：色の順位と合うダミーにする

上位3つに金、銀、銅の色が付く集計表で、数字だけを適当に変えると、色の順位と数字が食い違って不自然になります。そこで、セルの色に合う範囲からダミーの金額を決めました。

1. 空いた行の濃い縦線と横線から、列と行の境界を測る（シートの配置ごとに表にする）
2. FFmpegで区間を生の画素データ（`rawvideo rgb24`）にして<Term>Python</Term>へパイプで渡し、1コマずつ描き替えてFFmpegに戻す
3. コマごとに、セルの背景色（明るい画素で一番多い色）で金、銀、銅、白に分ける
4. 分類ごとの範囲（例：金は45,000〜80,000、白は1,000〜15,000）から、配置、行、列のハッシュで値を決める
5. 背景色で塗り、同じ書体と大きさで右寄せに描く

ハッシュで値を決めるので、同じシートが映っている間は値がちらつきません。合計の列は月の値の和にし、合計の色の順位と合わない場合だけ色の範囲の値にします。

~~~bash
ffmpeg -v error -ss "$START" -t "$LEN" -i "$SRC" -f rawvideo -pix_fmt rgb24 - \
  | python dummy.py sheet \
  | ffmpeg -v error -y -f rawvideo -pix_fmt rgb24 -s 1908x1030 -r 30 -i - \
      -c:v libx264 -crf 8 -pix_fmt yuv444p middle.mp4
~~~

配置を判定できないコマは、数字の範囲をモザイクにして安全側に倒します。

## つまずいたところ

- **カーソルの色の判定**：録画のカーソル（黄緑）を元に戻す処理で、金のセルの濃い黄色をカーソルと誤認し、元の数字が戻ってしまいました。「緑が赤より25以上強い」画素に限り、収縮処理で塊だけを残すようにしました
- **文字のにじみ**：ClearTypeのにじみに緑がかった画素があり、カーソル扱いになりました。これも収縮処理で除けます
- **自動の確認が必要**：目で見た一覧では、元の数字が戻ったコマに気づきにくいです。全コマで「数字があるのに描き替わっていないセル」を数え、使う区間で0件にします
- **消し残しの確認**：原寸のコマで、塗った帯の上下を見ます。ダイアログがかぶる行で、文字の切れ端が1px残ったことがありました
