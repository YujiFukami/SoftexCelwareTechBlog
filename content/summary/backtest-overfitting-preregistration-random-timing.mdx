売買ルールを過去のデータで何百通りも試し、一番良いものを選ぶと、偶然でも高い収益率が出ます。後から期間を分け直しても、一度見たデータは未使用には戻りません。売買の回数が10〜20回と少ない場合は、今後のデータを待って判断すると数年かかります。

ここでは、暗号資産の売買ルールを1,536通り探索した研究で使った、<Term>過学習</Term>を確かめる手順を紹介します。投資の助言ではなく、<Term>バックテスト</Term>の結果を検証する方法の紹介です。

## 3点セットで進める

1. **候補の凍結**：上位の候補について、全パラメーター、データの版、費用、約定の仮定、日時を1つのJSONに保存する。`open(path, "x")`で開き、上書きできないようにする
2. **合格基準の事前登録**：結果を見る前に、合格、不合格、保留の条件を数値でファイルに書く。判定するスクリプトは登録ファイルを読んで判定する。登録時にスクリプトのSHA-256を記録し、実行時に変わっていないかを確認する
3. **2つの検証**：探索に一度も使っていない別の期間へ、凍結した条件を1回だけ当てる。また、無作為な売買と比べる

## 無作為売買との比較

実際の売買と決済回数と各保有時間を同じにし、売買の時期だけを無作為に置き直した売買を多数作ります。実際の成績が、その中で上位何%に入るかを測ります。

~~~python
holds = (sells - buys).astype(np.float64)  # 実際の各保有時間
flat = span - holds.sum()                   # 保有していない時間の合計

shuffled = rng.permuted(np.tile(holds, (size, 1)), axis=1)              # 保有の順番を入れ替え
gaps = rng.dirichlet(np.ones(count + 1), size=size)[:, :count] * flat   # 空き時間を無作為に分割
entries = start + np.cumsum(gaps, axis=1) + np.cumsum(shuffled, axis=1) - shuffled
exits = entries + shuffled

ratio = price_at(times, prices, exits) / price_at(times, prices, entries)
results = np.prod(ratio * cost_factor, axis=1) - 1   # 費用は実際と同じ
p_value = (np.sum(results >= actual) + 1) / (simulations + 1)
~~~

`price_at`は、時刻の配列から`searchsorted`で価格を引く関数です。<Term>NumPy</Term>のベクトル計算により、100万通り×23決済でも数十秒で終わります。

比較の前に、実際の売買の成績も同じ簡略式で計算し、シミュレーターの成績と一致することを確かめます。この事例では、差が0.5ポイント未満であることをassertで確認しました。

## 判定のポイント

- **探索した数で割る**：1,536通りの中の最上位なら、偶然ではないと言える目安は p ≤ 0.05 ÷ 1,536 です。単独で p = 0.08% でも、1,536通りを試せば偶然で1件ほど出る水準です
- **判定は3段階にする**：合格と不合格の間に「保留」を置く。決済回数の最低数も基準に入れる
- **本番データの前に合成データで通す**：1回限りの検証は、途中でクラッシュして実行し直すと「1回限り」が崩れる。乱数で作った価格で、登録から判定までを一度通しておく
- **別の市場のデータは、考え方が通用するかの確認として扱う**：元の市場での成績とは言わない
- **公開データは公式のチェックサムを確認する**：手元の別粒度のデータと集計値を突き合わせて、列の対応と時刻の単位も検証する

保有時間はルールの結果によって決まるので、無作為比較は目安です。利益を伸ばして損失を切るルールでは、長い保有が上昇局面に偏ります。

## 落とし穴：連続運用の資産で直前の成績を測ると歪む

「過去の区間で選び、次の区間で試す」検証で、直前の成績を各ルールの連続運用の資産推移から切り出して測ったところ、誤った選択が起きました。

- 売買の多いルールは、費用で資産がほぼゼロになり、最低注文数量を下回って売買できなくなる
- 売れなくなったルールは少量を持ち続けるだけになり、資産が価格と同じ動きをするので、直前の成績が良く見えて選ばれてしまう

直前の成績は、その区間を資金100%から新しく運用して測ります。連続運用を使う場合は、資産が最低注文額の数倍を下回ったルールを除外します。登録済みの判定は変えず、結果を見た後の確認は「事後診断」として別のファイルに残します。

## 実施結果

- 探索期間の成績（+200%前後、買って保有は+19%）は、無作為比較で p = 0.014〜0.14% でした。探索した数を考えると、偶然でも説明できる水準です
- 未使用の6年4か月では、収益は買って保有の64〜80%、最大下落は57〜61%（買って保有は84%）でした。無作為より良い確率は91〜94%で、基準の95%に届かず「保留」となりました

探索期間の突出した成績は再現せず、過学習による上振れを数字で確認できました。
