ラジオ番組やニュース動画のBGMとジングルを、権利の心配がなく、いつでも作り直せる形で用意したいときの方法です。

依存するのは<Term>NumPy</Term>と<Term>FFmpeg</Term>だけで、外部の音源素材は使いません。6種類の音を約8秒で生成できます。

## 課題

- BGMは先頭から繰り返し再生されるので、ループの継ぎ目で「プツッ」と鳴ったり、残響が途切れたりする
- BGMが読み上げの声の帯域（300Hz〜4kHz）とぶつかると、声が聞き取りにくい

## 音色は3つで足りる

すべてNumPyのベクトル計算で作ります。中心になるのはFM合成のベルです。変調の深さを時間とともに減らすと、澄んだ余韻になります。

~~~python
def bell(f, dur, amp, bright=1.0, ratio=3.5):
    t = np.arange(int(dur * RATE)) / RATE
    env = np.exp(-t * 3.0 / dur) * np.minimum(1.0, t / 0.004)
    index = bright * 1.6 * np.exp(-t * 9.0)
    return amp * env * np.sin(2 * np.pi * f * t + index * np.sin(2 * np.pi * f * ratio * t))
~~~

- やわらかい鍵盤：FMの比を1:1にし、変調を浅くする
- パッド：倍音4本（1、0.28、0.08、0.03）を少しずつずらして3本重ね、なめらかな立ち上がりと減衰、ゆっくりした揺れを付ける

## ループは「円環」で作る

ここが一番大事な点です。

音を置くとき、ループの終わりからはみ出した部分を、先頭に回り込ませて足します（インデックスを`% n`にする）。和音の重なりも、ループをまたいでつながります。

残響とEQは、<Term>FFT</Term>で長さ`n`のまま（円環畳み込みとして）掛けます。残響の尾が先頭に回り込むので、ループの頭でも響きが続きます。

~~~python
spec = np.fft.rfft(buf, n=n, axis=1)               # n はループの長さ（パディングしない）
rev = spec * np.fft.rfft(ir[:, :n], n=n, axis=1)   # 円環畳み込み：残響がループの頭に回り込む
out = np.fft.irfft((spec + wet * rev) * eq_gain, n=n, axis=1)
~~~

ジングルのような単発の音は逆に、`n + len(ir)`までゼロで埋めて通常の畳み込みにし、最後を切ってフェードします。

継ぎ目の確認は、`abs(x[:, 0] - x[:, -1])`（最後と最初の標本の差）が、隣り合う標本の差の平均と同じくらいかで判断します。実測では0.0005と0.0014で、継ぎ目はありませんでした。以前の仮のBGMでは0.039で、継ぎ目が聞こえていました。

## 声の帯域をあける

- BGMは「低い持続音（250Hzまで）」と「まばらな高いベル」で作り、真ん中をあける
- FFTのついでに、1.2kHzを中心とする対数ガウスの谷（最大-5dB）を掛ける。40Hz以下も落とす
- 確認は、300Hz〜4kHzのエネルギーの割合で行う（新しいBGMは1.8%、以前の仮のBGMは28%）

## 繰り返しを目立たせない

- 高いベルの位置と音は、種を固定した乱数で決める。毎回同じ音ができるが、小節ごとには違う並びになる
- 和音は8秒×6の48秒で一巡させる。60BPMなら4秒で1小節なので、割り切れる

## 書き出しの音量

ピークを-3dBFSにそろえた後、`ffmpeg -af ebur128`で<Term>LUFS</Term>を測り、前の音源と同じLUFSまで下げます（上げることはしません）。こうすると、動画のテンプレートにあるBGMの音量設定を変えずに差し替えられます。

48kHz、16bit、ステレオのWAVは、Python標準の`wave`モジュールで書き出せます。

~~~python
data = (x.T * 32767).astype("<i2").tobytes()
~~~

## 番組らしさを出すコツ

- 4音程度の短いモチーフを決め、オープニング、エンディング（逆行）、区切りのジングル、ショート動画で使い回すと統一感が出る
- 暗い話題の日にも流すので、長調でもsus4やadd9など、決着感を弱めた和音にする

継ぎ目、帯域、音量は数値で確認できますが、耳での確認は欠かせません。
